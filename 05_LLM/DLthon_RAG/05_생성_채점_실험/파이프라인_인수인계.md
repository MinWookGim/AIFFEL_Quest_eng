# 생성 파이프라인 인수인계 — 여기서부터 만지시면 됩니다

**한 줄 이야기 -> 대본 -> 그림체 검색 -> 4컷 생성 -> 채점**이 끝까지 도는 코드입니다.
라이브 데모나 성능 튜닝을 이 위에서 하시면 됩니다.

```
pipeline_e2e.py     ★ 여기서 시작. 끝까지 도는 뼈대
cut1_guard.py         생성 조건 3개 비교 실험 (독립 / 순차 / 컷1 보증)
ab_prev_cut.py        앞 컷 물리기 2x2 실험
style_ceiling.py      그림체별 "천장" 측정 — 점수를 절대값으로 읽지 않기 위해
gate.py               편 단위 품질 게이트 (복붙 상한 포함)
결과/                  위 실험들의 산출물 (json + 그림)
```

## 1. 돈 안 쓰고 먼저 돌려보세요

생성 API 를 안 부르는 모드가 있습니다. **이걸로 파이프라인이 어떻게 도는지부터 보시면 됩니다.**

```bash
python pipeline_e2e.py --dry-run              # 검색·눈금까지만. 생성 직전에 멈춤
python pipeline_e2e.py --mock --no-llm        # 완주. 생성은 자리표시 이미지, 대본도 목. 완전 무료
```

진짜로 그림을 뽑을 때만 돈이 듭니다.

```bash
python pipeline_e2e.py                        # 1회 완주 약 $0.18 (4컷)
python pipeline_e2e.py --sequential           # 앞 컷을 물려서
python pipeline_e2e.py --target vec_undraw    # 목표 그림체 바꾸기
```

**필요한 것**: `daypack_v2` 폴더(저장소에 없습니다. 팀 드라이브에서 받으세요)와
진짜 생성을 할 때만 `~/.config/openai/api_key`.

## 3. 만지면 좋은 자리 (일부러 비워둔 것들)

`pipeline_e2e.py` 는 어댑터 4개를 주입받는 모양입니다. 진현님 그래프에 그대로 꽂을 수 있게 맞췄습니다.

| 자리 | 지금 상태 | 해볼 만한 것 |
|---|---|---|
| **생성 프롬프트** | 레퍼런스를 그대로 물리고 "스타일을 따르라"고만 함 | ★ **여기가 병목입니다.** 목표 그림체를 **말로 묘사**해 같이 넣기 (Midjourney 문서도 이 방법을 권합니다) |
| 컷1 선별 | best-of-3 을 Gram 점수로 고름 | N 을 키우거나, 후보가 전부 빗나갈 때의 처리 |
| 컷 간 일관성 판정 | 복붙 상한(코사인 0.95)만 봄 | 절대 코사인은 판별 실패(같은 그림체 0.668 vs 다른 그림체 0.653). **라벨 일치도**가 더 잘 갈립니다 |
| 재생성 루프 | **꺼져 있음** | 지금 채점기로 켜면 안 됩니다 (판정 정확도 0.440 = 56% 오판). 선별기로 쓰는 게 먼저 |
| 텍스트 쿼리 경로 | 이미지 질의만 | 한국어 텍스트 쿼리가 영어의 1/3 (0.1027 vs 0.3327) — 별도 설계 필요 |

## 4. 라이브 데모로 쓰실 때

**생성을 실시간으로 부르지 않는 걸 권합니다.** 실측으로 4컷 한 편에 **평균 89초(75~108초)** 걸리고,
안전필터 거부도 16편 중 1편 있었습니다. 발표 중에 멈추면 그게 마지막 장면이 됩니다.

미리 뽑아둔 4컷을 보여주고, 진짜 호출은 한 건만 뒤에서 돌리는 쪽이 안전합니다.
`결과/` 의 그림들은 그대로 쓰셔도 됩니다.
