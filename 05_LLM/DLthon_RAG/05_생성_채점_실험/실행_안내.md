# 실행 안내 — 돌려보려면 데이터가 먼저 필요하다

여기 스크립트들은 **내 로컬 작업 폴더에서 돌던 것을 그대로 옮긴 것**이라, 받자마자 실행하면
`FileNotFoundError`가 난다. 임베딩 캐시(`.npy`)를 저장소에 안 올렸기 때문이다 (용량 때문).

읽는 것만이 목적이면 그냥 읽으면 된다. 코드 자체는 짧고 주석을 달아뒀다.

## 무엇이 없나

| 필요한 파일 | 무엇 | 어떻게 만드나 |
|---|---|---|
| `verify/ink_emb.npy` | 수묵화 코퍼스의 CLIP 임베딩 (N, 512) | `02_팀_공유/kit/encoders/clip_base.py`의 `encode()` |
| `verify/ink_gram.npy` | 같은 코퍼스의 Gram VGG19 임베딩 (N, 174560) | `02_팀_공유/kit/encoders/gram_vgg19.py`의 `encode()` |
| `verify/ink_style.npy` | 그림체 라벨 (N,) | `meta.csv`의 `style` 컬럼 |
| `verify/ink_content.npy` | 원본 ID (N,) | `meta.csv`의 `content` 컬럼. 같은 원본을 이웃에서 빼는 데 쓴다 |

코퍼스 자체는 AI-Hub 이용정책 때문에 저장소에 없다. 팀 드라이브의 데이터팩을 쓰면 된다.

## 만드는 법

`02_팀_공유/kit/` 옆에 두고 이렇게 뽑으면 된다. 인코더 규격은 `score.py`가 쓰는 것과 같다.

```python
# 프로젝트 루트에서 실행. verify/ 폴더를 만들어 거기 저장한다
import csv, os, numpy as np, importlib.util
from PIL import Image

PACK = "daypack_v1"                      # 팀 드라이브의 데이터팩 경로
rows = list(csv.DictReader(open(f"{PACK}/meta.csv", encoding="utf-8")))
imgs = [Image.open(f"{PACK}/{r['file']}").convert("RGB") for r in rows]

os.makedirs("verify", exist_ok=True)
np.save("verify/ink_style.npy",   np.array([r["style"] for r in rows]))
np.save("verify/ink_content.npy", np.array([r.get("content", "") for r in rows]))

for kind, path in [("emb", "kit/encoders/clip_base.py"), ("gram", "kit/encoders/gram_vgg19.py")]:
    spec = importlib.util.spec_from_file_location(kind, path)
    mod = importlib.util.module_from_spec(spec); spec.loader.exec_module(mod)
    np.save(f"verify/ink_{kind}.npy", np.asarray(mod.encode(imgs), dtype="float32"))
```

Gram 쪽은 차원이 17만이라 1,259장이면 900MB 가까이 된다. 디스크 여유를 보고 돌릴 것.

## 돌리는 법

프로젝트 루트(= `verify/`가 보이는 자리)에서 실행한다.

```bash
python consistency_baseline_v2.py                  # CLIP 으로
EMB=verify/ink_gram.npy python consistency_baseline_v2.py   # Gram 으로
python ensemble_test.py
python best_of_n_test.py
python gate.py                                     # 데이터 없이도 돈다 (예시 4편으로 자체 점검)
```

`gate.py`만 데이터 없이 그냥 돈다. 판정 로직만 들어 있어서다.

## `ab_prev_cut.py`는 다르다

이건 실제로 이미지를 생성하므로 **돈이 든다** (16편 기준 약 3달러). 그리고 OpenAI 키가 필요하다.
먼저 이걸로 계획과 예상 비용만 확인할 수 있다.

```bash
python ab_prev_cut.py --dry-run
```

경로 기준이 `__file__`의 두 단계 위라, 옮겨 쓸 때는 파일 위쪽 `ROOT`·`PACK` 상수를 자기 환경에 맞게
고쳐야 한다. 중간에 끊겨도 `results.json`에 이어 쓰고 이미 끝난 조건은 건너뛴다.
