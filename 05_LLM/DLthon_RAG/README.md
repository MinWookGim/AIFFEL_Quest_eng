# DLthon2 — 그림체(Style) Visual RAG: 4컷 만화 생성

한 줄 이야기를 넣으면 원하는 그림체를 유지한 4컷 만화가 나오게 하는 프로젝트다.
"이 그림체로 그려줘"를 말로 시키는 대신, 그 그림체의 실물을 코퍼스에서 검색해다 생성에 물린다.
찾아오는 대상이 문서에서 그림으로 바뀌었을 뿐 구조는 RAG 그대로다.

- 기간: 2026-07-30 ~ 08-11 (중간에 방학 8/1~8/9, 실작업은 4일)
- 나는 이 주제를 제안했고 팀장을 맡았다. 팀원: 강경수, 김수경, 조희연, 채진현
- 팀 결과물은 별도 팀 저장소에 모인다. **여기는 그 중 내 몫의 기록**이다
- **결론부터 보려면 `06_발표/README.md`** 를 먼저 읽으면 된다 (프로젝트 전체 지도 겸 발표 해설)
- 참고한 논문·문서·데이터 출처는 **`REFERENCES.md`** 한곳에 모아뒀다

## 폴더 지도 — 역할이 바뀐 순서대로 읽으면 된다

| 폴더 | 시기 | 그때의 내 역할 | 내용 |
|---|---|---|---|
| `01_기획/` | 7/28~29 | 기획자 (혼자) | 제안서, 지원 발표자료(PDF), 시작 전 준비 기록(PREP.md) |
| `02_팀_공유/` | 7/30 오전 | 배포자 | 팀 온보딩용으로 만들어 배포한 것 — 시작 노트북, 자동 채점기(kit), 재현 스크립트(scripts), 브리핑·평가규칙(docs) |
| `03_빌드업/` | 7/30 오후~ | 팀원 | 회의에서 맡은 오케스트레이션 갈래 — 랭그래프·오토젠 빌드업 노트북 1·2편, 진행 기록 |
| `04_임베딩_실험/` | 7/30 밤~ | 같이 공부 | 팀 대화에서 나온 관찰("CLIP은 사물을 본다")을 가설 2개로 검증해본 실험 노트북 |
| `05_생성_채점_실험/` | 8/3 | 혼자 연구 | 생성 쪽 채점자 설계 - 품질 게이트, 천장 측정, 앞 컷 물리기 실험 |
| `06_발표/` | 8/11 | 발표자 | **최종 발표 자료와 정리 문서** — 슬라이드가 어느 실험·어느 코드에 기대는지 쪽수로 연결해뒀다. 팀원 기여도 여기 |

01의 준비물과 02의 배포물은 팀 성과가 아니라 **팀이 넘어야 할 출발선**으로 뒀다.
경계를 날짜로 자른 이유는 `01_기획/PREP.md` 맨 위에 적어뒀다.

## 여기에 없는 것 (일부러 안 올림)

- **코퍼스 원본 이미지·데이터팩 전부** — AI-Hub 이용정책(제3자 제공 제한)과 출처별 재배포 제한 때문에
  팀 내부 드라이브로만 공유한다. 제안서의 예시 이미지 3종도 같은 이유로 뺐다
- 임베딩 캐시(.npy), zip — 재계산 가능한 대용량

## 잣대 하나만 미리

리더보드 점수 = 가장 가까운 5장 중 같은 그림체 비율. 절대값 대신 **무작위로 찍었을 때 기대값의 몇 배인지**로 읽는다.
숫자는 코퍼스 버전이 바뀌면 전부 무효로 치고 다시 잰다 — 상세는 `02_팀_공유/docs/팀_평가규칙.md`.
